# Product vision

FrameRinse is a small self-hosted utility for cleaning a photo before posting it.
It should be easy to open from an iPhone, keep expensive work on the server, and
delete temporary files without manual server maintenance.

The app provides practical reduction, not anonymity: server-side re-encoding,
generic filenames, optional resolution reduction, solid manual covers, and a
final metadata check. It does not claim to recognize every identifying detail
inside the visible image or control what a social platform records after upload.
